# Main Focus Website — Changelog

This changelog records the changes, improvements and new features implemented during the development of the Main Focus website.

## Version 2.0 — Website Improvements and JavaScript Development

### 1. HTML Structure and Dynamic Content
 Improved the structure of the Services page.
 Moved product image information from the HTML Services page into the services.js JavaScript file.
 Created six product arrays for Summer Wear, Winter Wear, Formal Wear, Footwear, Sunglasses and Headwear.
 Added JavaScript loops to display products dynamically on the Services page.
 Used DOM manipulation to insert product images and information into the relevant HTML sections.
 Organised products into their correct categories.

### 2. Product Search Functionality
 Added a product search feature using JavaScript.
 Created a Search button to allow customers to search for products.
 Added a Clear Search button to restore all products after a search.
 Improved the search functionality to work across all six product categories.

### 3. Interactive Elements
 Added an FAQ accordion to the Enquiries page.
 Implemented Open All and Close All buttons for the frequently asked questions.
 Added hover animations to navigation links.
 Added hover effects to buttons to improve the website's appearance and user experience.
 Added Back to Top buttons to the Home and Enquiries pages.
 Implemented smooth scrolling when users click the Back to Top button.

### 4. Gallery and Lightbox Improvements
 Integrated the Lightbox gallery functionality.
 Added image navigation using Next and Previous arrows.
 Enabled users to close the image viewer using the close button.
 Corrected image paths for the Lightbox navigation arrows, close button and loading animation.
 Tested the gallery to confirm that the images open and navigation works correctly.

### 5. Interactive Map
 Added an embedded Google Map to the website.
 Enabled visitors to view the map and access directions.

### 6. SEO Improvements
 Added relevant page titles to all five HTML pages.
 Added meta keywords to improve the website's search engine information.
 Added individual meta descriptions to the Home, About, Services, Contact and Enquiries pages.

### 7. Image Improvements
 Renamed product image files using clearer and more descriptive filenames.
 Added alternative text  or alt attributes to product images in all six product categories.
 Corrected image paths after renaming files.
 Tested the website to confirm that the product images still display correctly.

### 8. Enquiry Form Improvements
 Added and tested required fields for customer enquiries.
 Added email validation to accept Gmail addresses ending in @gmail.com.
 Added a success message after a valid enquiry form submission.
 Improved the form's response by hiding the form and displaying a thank-you message after successful validation.

### 9. Contact Page Improvements
 Made the email address clickable using the mailto: link.
 Made the phone number clickable using the tel: link.
 Tested the links to confirm that they open the relevant email or calling application.

### 10. Responsive Design and Testing
 Retained the responsive design improvements implemented during Part 2.
 Tested the website on desktop, tablet and mobile screen sizes.
 Checked navigation and images across all five website pages.
 Confirmed that the responsive layouts continued working after the JavaScript improvements.
